# 🚀 TaskFlow Pro - Aurex Web Engineering Internship (Week 4)

A modern, responsive, and feature-rich Task Management application built as part of the Aurex Full-Stack Engineering Internship Week 4 assignment.

## 👩‍💻 Developer
* **Name:** Zainab Fatima

## ✨ Features
* **Add & Manage Tasks:** Easily add daily tasks with descriptions.
* **Priority Levels:** Assign and filter tasks by Low, Medium, and High priorities with color-coded badges.
* **Interactive Filtering:** Toggle between All, Active, and Completed tasks instantly.
* **Dynamic Progress Bar:** Real-time completion percentage tracking.
* **Local Storage:** Your tasks persist in your browser so you never lose data on refresh.
* **Responsive Design:** Clean, modern UI styled with custom CSS and FontAwesome icons.

## 🛠️ Technologies Used
* **HTML5** (Semantic Markup)
* **CSS3** (Flexbox, Variables, Glassmorphism touches)
* **JavaScript (ES6+)** (DOM Manipulation, LocalStorage, State Management)
* **FontAwesome & Google Fonts**
